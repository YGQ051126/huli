# 护理管理平台

一个专为养老院设计的综合护理管理系统，提供数字化护理解决方案。

## 项目概述

本系统采用前后端分离架构，为养老院提供完整的护理管理功能，包括院民信息管理、护理记录、预约系统、费用管理、活动相册等核心功能。

## 主要功能

### 亲属端功能
- 院民信息查看
- 在线预约探视
- 费用查询与支付
- 个性化服务申请
- 消息通知接收

### 工作人员端功能
- 日常护理记录
- 院民健康监控
- 任务管理与执行
- 活动相册管理
- 在线沟通交流

### 管理端功能
- 用户信息管理
- 员工权限分配
- 公告发布管理
- 数据统计报表
- 审批流程处理

## 技术架构

- **前端**: Vue 3 + TypeScript + Element Plus
- **后端**: Django REST Framework + MySQL
- **部署**: 支持本地开发和云端部署

## 快速开始

### 环境要求
- Python 3.8+
- Node.js 16+
- MySQL 5.7+

### 启动步骤
1. 克隆项目到本地
2. 配置数据库连接
3. 安装后端依赖并启动服务
4. 安装前端依赖并启动应用

详细启动方法请参考项目中的启动文档。

## 项目特色

- **三端分离**: 亲属、工作人员、管理员三个角色独立界面
- **模块化设计**: 功能模块清晰，便于维护和扩展
- **响应式界面**: 适配各种设备屏幕
- **权限管理**: 细粒度的角色权限控制
- **数据安全**: 完善的数据保护机制

## 适用场景

- 养老院护理管理
- 医疗机构患者管理
- 社区养老服务
- 家庭护理服务
